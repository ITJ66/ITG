Инструменты визуализации

Визуализация информации — это её представление в текстовой, графической или интерактивной форме для улучшения восприятия, запоминания и вовлеченности.

Динамический (изменяемый) контент может быть поделен на три блока. Каждый блок выполняет свою задачу, развлекает аудиторию сайта и позволяет запоминать большую часть информации:

Информирует, обучает.
Например, текстовый блок, «Термины», «Фотогалерея», «Таблицы», «Цитаты», интерактивные инструкции и тренажёры.
Выявляет и устраняет проблемы, отвечает на вопросы.
Графики, «Вопрос / ответ», «Схема-дерево», интерактивные тесты, чек-листы, сравнительные таблицы и видео.
Продает товары или услуги.
Например, «Обратная связь» (файлы на скачку, социальные сигналы и формы связи), «Презентация компании», «Демонстрация товара» и «Отзывы».
SVG - это язык для описания двумерной графики в XML. Он позволяет создавать три типа объектов: векторные фигуры, растровые изображения и текст. SVG поддерживает интерактивность и анимацию с помощью DOM и событий.

Интерактивный контент для сайта

Интерактивный контент - это контент, с которым пользователь может взаимодействовать.

Посетитель сайта сам меняет настройки отображения информации и выбирает собственный (персональный) путь изучения материала.

I. Слайдер вида "До / После"

Пример отрисовки логотипов по фото с помощью SVG.

II. Гистограммы, графики, круговые диаграммы

Интерактивное представление статистических данных.

III. Блок-схемы (планы и чертежи)

Пример визуализации логики, моделирования процесса.

IV. Тренажёр для отработки навыка (интерактивные инструкции)

Полезные комбинации клавиш, доступные на персональном компьютере.

V. Многослойные карты (атласы)

Карта проезда с элементами, точками интереса (POI) и анимацией.
